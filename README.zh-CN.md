# WinWitch

[English](README.md) | **简体中文**

KDE Plasma 6 / Wayland 下的字母窗口切换器。按 `Meta+F` 浮出一层卡片，每个窗口对应一个字母，
按字母直接跳过去。

它不是 Alt+Tab 的替代品。它解决的是另一种情形：你**已经知道**要哪一个窗口，
不想为了到那儿而逐个越过其它窗口。

## 功能

- **一个字母一个窗口。** 最多 26 个目标，顺序与你的任务栏图标一致。
- **固定未启动的应用也是一等公民。** 它同样占一个字母位：按一次进入冷却（卡片上浮出
  走空的饼图），再按一次才启动。冷却期间按别的字母会直接切过去，所以不会误启动。
- **窗口状态看得见。** 卡片能看出哪个窗口在前台、哪个已最小化、哪个还没启动。
- **选中已在前台的窗口会把它最小化**，与点击任务栏图标的行为一致。可在面板设置里关掉。
- **刻意没有自动超时。** 浮层一直在，直到你按下字母或 `Esc`。

## 依赖

- KDE Plasma 6 / Wayland
- MoonBit 工具链——**建议用每夜构建**（`MOONBIT_INSTALL_VERSION=nightly`）。
  稳定版常缺本项目用到的语言特性
- `qdbus6`（来自 `qttools`）与 Qt 6 的 QML 运行时

## 从源码安装

```bash
git clone https://github.com/conglinyizhi/winwitch
cd winwitch
make install     # 编译 helper，装 KWin 脚本、面板组件与浮层
make reload      # 让 KWin 与 plasmashell 重新加载
```

装完还有两步（各做一次）：

1. 把 **WinWitch** 面板组件加到任务栏。它负责提供任务栏顺序与应用图标；
   少了它，字母就对不上你的图标位置。
2. 默认快捷键是 `Meta+F`，想改就在系统设置里改。

发布页同时提供静态链接的 helper 与配套文件（`*-addon.tar.gz`）。
一键安装脚本还在计划里；在那之前，上面这条源码路线是受支持的方式。

## 使用

| 按键 | 行为 |
| --- | --- |
| `Meta+F` | 打开浮层 |
| `<字母>` | 切到该窗口 |
| `<字母>` 按两次 | 启动固定应用（第一次只是进入冷却） |
| `Esc` | 关掉，不切换任何窗口 |

## 配置

面板组件的设置分两页：

- **外观** —— 浮层位置、最多几列、是否显示窗口标题、背景风格
- **行为** —— 启动器确认时间（那个"按两次"的等待窗口，300–5000 毫秒）、
  以及选中已在前台的窗口时是否最小化它

## 架构

四个部件，各管一件它最擅长的事：

```
Meta+F
  |
  +- KWin 脚本       快捷键、窗口列表、激活与最小化
  +- MoonBit helper  会话状态与字母分配，以 D-Bus 服务形式对外
  +- 面板组件        任务栏顺序与应用元信息（图标、名字、设置页）
  +- 浮层（QML）     画卡片、接按键
```

浮层不能激活窗口（那是合成器的权限），也读不到任务栏模型（只有面板能），
所以选择要经 helper 转一手、由 KWin 执行。字母表也归 helper 持有——
这就是它必须是个独立进程、而不能塞进某个 QML 部件里的原因。

**字母为什么能对齐任务栏**：KWin 给的窗口枚举顺序与任务栏并不一致，
所以由面板把任务栏的图标顺序推给 helper，helper 按槽位分配字母。
一旦你按下某个键，字母表就冻结到这次选择结束——否则窗口集合在操作期间变化
（比如启动的应用把自己弹出来）会让手指底下的字母突然换意思。

## 开发

```bash
make ci              # 静态检查、64 个单元测试、配置键对齐检查
make reload          # 重载 KWin 脚本与 plasmashell
make status          # 进程、外观配置、已安装构建标识
make flash SEC=3     # 打开浮层并在若干秒后自动取消，方便快速看一眼
make cancel          # 逃生口（刻意不设自动超时）
```

`core/` 里的逻辑刻意不依赖 KWin、Qt 和 D-Bus，所以 `moon test` 在任何环境下都能跑。

`scripts/build-static.sh` 产出静态链接的 helper，发布流程用的就是它。
