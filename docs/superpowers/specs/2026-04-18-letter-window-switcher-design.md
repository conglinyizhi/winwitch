# Plasma 6 字母窗口切换器设计

## 目标

为 KDE Plasma 6 Wayland 提供一个可从任务栏图标右上角显示字母标签的窗口切换器。用户按 `Super+F` 进入选择模式，按标签对应的字母激活窗口，按 `Esc` 立即取消且不切换窗口。

## 已确认的交互

```text
空闲
  └─ Super+F → 进入选择模式，任务栏图标显示 A-Z 标签
       ├─ A-Z → 激活对应窗口并退出
       ├─ Esc → 紧急退出，不激活任何窗口
       └─ 超时 → 自动退出
```

标签只放在任务栏图标右上角，不显示中央列表。窗口按任务栏当前顺序分配字母，默认使用 A-Z；超过 26 个窗口时，第一版只显示前 26 个可切换窗口并在后续扩展多层选择。

## 平台边界

目标平台是 Plasma 6 + Wayland。普通 QML Plasmoid 无法可靠地捕获 `Super+F` 后的任意下一个字母，也不应读取原始键盘设备。因此输入层使用 KWin 脚本注册入口快捷键，并配合受控的键盘吸收器完成模式内的字母和 `Esc` 处理。键盘吸收器只在选择模式活动时运行，不记录输入，不持久化按键内容，模式结束立即释放。

## 架构

### 任务栏显示层

一个 Plasma 6 QML 任务栏部件，基于 Plasma Task Manager 的任务模型获取窗口顺序和图标。每个任务项拥有一个独立的标签叠加层：

- 标签位于图标右上角；
- 默认黄色背景、黑色文字、轻微圆角；
- 选择模式关闭时完全隐藏；
- 任务列表变化时重新生成窗口到字母的映射；
- 映射通过本地 IPC 或共享配置与 KWin 输入层同步。

第一版允许作为独立的 Icons-Only Task Manager 替代品安装，避免修改系统 `/usr/share` 下的 Plasma 文件。

### KWin 控制层

KWin 脚本负责：

- 注册 `Meta+F`；
- 枚举正常任务窗口并生成稳定的 `internalId` 映射；
- 进入和退出选择模式；
- 在命中字母时激活仍然存在的目标窗口；
- 对窗口创建、关闭、激活和任务栏排序变化刷新映射；
- 在 `Esc` 时优先清理状态，阻止后续动作；
- 在脚本重载或异常清理时隐藏标签。

窗口激活只调用 KWin 的窗口对象和工作区 API，不使用 `wmctrl`、X11 窗口 ID 或模拟鼠标点击。

### 输入吸收层

独立的用户级 helper 只负责模式内输入：

- 通过 KWin 脚本提供的模式状态判断是否工作；
- 吸收 A-Z 和 `Esc`；
- 将按键转换为字母或取消事件发回 KWin 脚本；
- 超时后自动退出；
- 退出时释放输入资源，即使目标窗口已经关闭也必须执行清理。

具体输入后端优先复用 Wayland/KWin 可用的合成器级输入接口；若当前发行版不提供可用接口，安装说明必须明确所需权限和降级行为，不静默读取所有键盘事件。

## 状态机

状态只允许有两个值：`Idle` 和 `Selecting`。

进入 `Selecting` 时保存当前任务快照和会话令牌。所有来自旧会话的字母、取消和超时消息都必须被忽略，防止旧 helper 事件误操作新窗口映射。

`Esc` 的处理优先级高于字母匹配和窗口激活：

1. 标记当前会话已取消；
2. 隐藏全部标签；
3. 停止超时计时器；
4. 释放输入吸收器；
5. 丢弃窗口映射；
6. 不调用窗口激活 API。

## 错误处理

- 入口快捷键冲突时在安装文档中提示用户重新绑定；
- 目标窗口关闭或不再可激活时，退出选择模式并保持当前焦点；
- 任务栏模型暂时为空时隐藏标签，不激活错误窗口；
- helper 启动失败时允许 `Super+F` 安全退出，并通过日志给出原因；
- 禁止把任何普通键盘输入写入日志或文件；
- 所有 IPC 消息必须带会话令牌和有限消息类型。

## 验收标准

1. Plasma 6 Wayland 下能够安装并加载显示层和 KWin 脚本。
2. 按 `Super+F` 后，任务栏可切换窗口的图标右上角显示 A-Z 标签。
3. 按有效字母只激活对应窗口并退出模式。
4. 按 `Esc` 不切换窗口、隐藏标签并释放模式资源。
5. 选择模式超时自动退出。
6. 窗口在选择模式中关闭不会导致错误激活或残留标签。
7. helper 不记录普通键盘输入，退出后不继续监听。
8. 无 KDE/Wayland 运行环境时，至少能通过静态检查和单元测试验证状态机、字母分配和取消优先级。
